# Icons

- `desertbird.svg`: the DesertBird mark, a flat desert owl in a cowboy hat on a 96 by 96 view box. It has no poncho, so the shape stays readable at 16 and 48 pixels. The orange, red and tan come from the DesertFox logo palette. The hat is a lighter brown (`#8a5632`) so it shows on a dark toolbar, and the pupils keep the darker brown (`#3b2417`). It is the toolbar button icon and the manifest icon at 48 and 96.

# Icons

- `desertbird.svg`: the DesertBird mark, a flat owl in a cowboy hat on a 96 by 96 view box, in the DesertFox logo palette. It has no poncho, no hat band and big round eyes so it stays readable at 16 and 48 pixels. The hat brown is light enough to show on a dark toolbar. It is the toolbar button icon and the manifest icon at 48 and 96.
